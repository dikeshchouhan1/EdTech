# 📘 StudyNotion – EdTech Platform

StudyNotion is a full-stack **EdTech platform** built using the **MERN stack**.  
It allows users to explore courses, enroll online, and make secure payments using **Razorpay**.

---

## 🚀 Features

- User Authentication (Student / Instructor)
- Course creation & management
- Course enrollment system
- Secure payment integration with Razorpay
- Responsive and user-friendly UI
- REST API based backend

---

## 🛠 Tech Stack

**Frontend**
- React.js
- HTML, CSS, JavaScript
- Tailwind CSS

**Backend**
- Node.js
- Express.js

**Database**
- MongoDB

**Payment Gateway**
- Razorpay

---

## 🔐 Authentication

- JWT (JSON Web Token)
- Role-based access control

---

## 💳 Payment Integration

- Razorpay Checkout
- Secure payment handling
- Order creation & verification
